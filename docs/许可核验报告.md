# 许可核验报告（落地前复核清单第 17 节 · 许可类剩余项）

> 核验日期：2026-11-17。核验方式：访问各项目/模型的**官方许可页或官方仓库 LICENSE**，逐字取证。
> 本报告只覆盖方案第 17 节清单中与**许可**相关的剩余项；技术实测项（Chromium 支持、单帧耗时、运行环境实测等）不在本报告范围，仍按清单保持未勾选。
> **分类口径（严格三档，禁止把未知写成可商用）**：
> - **可商用**：官方许可页/仓库 LICENSE 明确允许商业使用（含附条件允许）。
> - **需授权**：官方明确为"非商用研究"或"商用需另行取得授权"——**当前不得商用**。
> - **未知**：官方页未给出可引用结论，或许可取决于未确定的第三方服务条款——**按不可商用处理**。

## 2. 取证明细（官方原文摘录）

### 2.1 人脸 embedding 权重 —— 结论：需授权（当前不得商用）
InsightFace 官方站 `https://www.insightface.ai/` "Licensing & Pricing" 区原文（2026-11-17 访问）：

- "Code released under MIT License — free for commercial use"（代码 MIT，商用免费）
- "Pre-trained models for non-commercial academic research only"（预训练模型仅限非商业学术研究）
- "Commercial use of models requires [contact us] … 人脸识别模型商业授权（buffalo_l、antelopev2、buffalo_s 等）"（模型商用需单独取得商业授权）

**关键判断**：MIT 只覆盖代码，**不覆盖预训练权重**。不能因"insightface 代码开源"就推断"人脸 embedding 权重可商用"。本项目按决策 #5/方案 20.2 保持 Sidecar 可选、人脸 selector 未实现（`BINARY_NOT_FOUND`），**无需商用授权即可正常运行**；一旦要启用 `anchor_region="face"`，必须先取得 InsightFace 商业模型授权。DeepFace 封装的 VGGFace/Facenet 权重同样为非商用研究授权，归入"未知"，当前未使用。

### 2.2 深度权重 Depth Anything V2 —— 结论：可商用
HuggingFace 官方模型卡 `depth-anything/Depth-Anything-V2-Small-hf` 的 README YAML front-matter 逐字为 `license: apache-2.0`（2026-11-17 访问 raw README）；官方仓库 `LiheYoung/Depth-Anything` 标注 Apache License 2.0。
**因此可商用**，使用时保留版权与许可声明。注意：本项仅指方案引用的 **V2** 权重；Depth Anything V1 的 checkpoint 曾采用非商用研究许可，不得混用推断。

### 2.3 中文字体 Noto Sans SC —— 结论：可商用（附条件）
Google Fonts 官方许可页 `https://fonts.google.com/specimen/Noto+Sans+SC/license` 原文（2026-11-17 访问）："This Font Software is licensed under the SIL Open Font License, Version 1.1."，版权 "Copyright 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'"。
OFL 1.1 允许商用、嵌入、再分发；条件是保留许可与版权声明、衍生字体不得使用保留字体名。满足即可商用。

### 2.4 音乐/画面素材 —— 结论：当前自产可商用，外部未知
当前唯一 BGM 由 ffmpeg `aevalsrc` 程序化合成（生成命令见 `fixtures/README.md`），无第三方版权输入，按 CC0 1.0 贡献；群像/人像图为 AI 生成工具产出，其可商用性取决于所用生成服务条款——`fixtures/README.md` 已诚实标注此项为"使用者自行确认"，本报告据此将其归入**未知**（非"可商用"）。**引入任何外部音乐/图片前必须逐项核验许可。**

### 2.5 其余已实证可商用项
HyperFrames、GSAP/CustomEase 由 recon 逐字实证（Apache-2.0 / GSAP No Charge）；RT-DETR、SAM、SAM2 为 Apache-2.0；Grounding DINO 官方仓库 Apache-2.0；PixiJS 为 MIT。以上均允许商用，随分发保留许可声明。**反向提醒**：DINOv2、SegFormer 等骨干为"仅研究/非商用"，不得因上游模型是 Apache 就推断其派生权重可商用。

## 3. 风险与行动项

1. **人脸 embedding（最高风险）**：保持 `anchor_region="face"` 为 `BINARY_NOT_FOUND`；任何商用启用前须取得 InsightFace 商业模型授权，否则禁用。
2. **AI 生成图片**：确认所用 image_gen 服务条款是否允许商用；不允许则替换为明确许可素材（如 Pexels/Unsplash，逐张确认条款）。
3. **外部素材准入**：建立"引入前逐项核验"规则——外部音乐、颗粒/光晕、字体、画面一律按未知处理，核验并留存 URL + 许可原文后才可标记可商用。
4. **权重下载复核**：下载 RT-DETR / Grounding DINO / SAM 权重时核对对应官方模型卡的 license 字段，避免混入非商用骨干。
